# Privacy Policy

Last updated: 2026-03-24

This Privacy Policy explains what data this website processes and why.

## 1. Summary

- No account system is used.
- No server-side database is required for normal operation.
- Core functionality runs in your browser.

## 2. Data Processed in Browser

This website may store limited local session data in your browser for usability, such as:

- Last selected device codename
- Last selected filter options

This data is stored using browser storage and remains under your browser profile.

## 3. Network Requests

When you use search and selection features, your browser makes requests to third-party sources (for example, public feed/index endpoints). Those services may receive:

- Your IP address
- Request headers/user agent
- Request time and endpoint path

Those endpoints are governed by their own privacy terms.

## 4. Analytics and Tracking

Default policy in this template:

- No advertising trackers
- No analytics SDK by default

If analytics are later added, this policy must be updated before deployment.

## 5. Cookies

This website does not set custom tracking cookies by default.

## 6. Data Sharing

The operator does not sell personal data. Data shown in the app is sourced from third-party public feeds.

## 7. Security

Reasonable safeguards are used, but no method of internet transmission or browser storage is fully secure.

## 8. Your Choices

You can clear local browser storage at any time from browser settings to remove remembered selections.
